Add a `summaryRef = useRef<HTMLDivElement>(null)` and attach it to the top summary-cards container (read the render — the grid with basket/movers cards; wrap or attach ref to the existing container div without changing layout/classes).
Handler (place near other handlers):
```tsx
  const handleShare = useCallback(async () => {
    if (summaryRef.current) {
      try {
        const dataUrl = await toPng(summaryRef.current);
        const a = document.createElement("a");
        a.href = dataUrl;
        a.download = "stats-watchlist.png";
        document.body.appendChild(a);
        a.click();
        document.body.removeChild(a);
        showToast("Stats image saved");
        return;
      } catch {
        // fall through to text
      }
    }
    const message = buildWatchlistShareText({ watchlist: products ?? [], displayCurrency, days });
    try {
      await navigator.clipboard.writeText(message);
      showToast("Copied to clipboard");
    } catch {
      const ta = document.createElement("textarea");
      ta.value = message;
      document.body.appendChild(ta);
      ta.select();
      try {
        document.execCommand("copy");
        showToast("Copied to clipboard");
      } catch {
        showToast("Couldn't copy share text");
      }
      document.body.removeChild(ta);
    }
  }, [products, displayCurrency, days]);
```
Check `useCallback`/`useRef` imports in Stats.tsx (useEffect/useMemo/useState imported — add the missing ones). Verify `buildWatchlistShareText` input shape in `lib/watchlist-share.ts` (`{watchlist, displayCurrency, days, now?}` — pass exactly these three; mobile stats passes the same three).
Header: read the `<h1>Statistics</h1>` header block and add a Share button beside it (copy icon — check lucide `Share2` export like Watchlist used; `aria-label="Share stats"`; disabled when `!products || products.length === 0`). Render toast div near container top (mirror Watchlist's fixed toast or simple status div — read file, reuse simplest existing pattern; if none, use the bordered status div).
